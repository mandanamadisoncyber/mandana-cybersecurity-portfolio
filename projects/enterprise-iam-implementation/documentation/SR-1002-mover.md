# Mover Process

## Service Request

SR-1002

Emma Taylor transferred from the Marketing department to the Sales department.

## IAM Activities

- Updated department attribute
- Updated job title
- Removed Marketing Users security group
- Added Sales Users security group
- Verified Administrative Unit assignment
- Confirmed least-privilege access

## Security Considerations

Access was updated to reflect Emma's new business responsibilities.

Removing obsolete group memberships prevents privilege accumulation and supports the principle of least privilege.
