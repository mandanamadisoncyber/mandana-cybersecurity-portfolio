# Authentication Methods

## Overview

This section documents the authentication methods configured within the Microsoft Entra ID tenant to provide secure user authentication while supporting modern identity management practices.

---

## Objectives

- Enable secure authentication methods
- Support passwordless authentication where appropriate
- Prepare users for Multi-Factor Authentication (MFA)
- Reduce reliance on legacy authentication methods

---

## Configuration

The following authentication methods were enabled:

- Microsoft Authenticator
- Passkey (FIDO2)
- Temporary Access Pass (TAP)
- Software OATH Tokens
- Email One-Time Passcode (OTP)

The following methods were disabled:

- SMS
- Voice Call
- Hardware OATH Tokens
- Certificate-based Authentication
- Verified ID
- QR Code Authentication

---

## Temporary Access Pass (TAP)

A Temporary Access Pass was issued to support secure onboarding of new users.

TAP provides a time-limited credential that allows users to register stronger authentication methods without requiring an initial password-based sign-in.

---

## Security Benefits

- Supports passwordless authentication
- Enables secure onboarding
- Reduces reliance on weaker authentication methods
- Improves overall identity security
- Aligns with Microsoft Entra identity best practices
