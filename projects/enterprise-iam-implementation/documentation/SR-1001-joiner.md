# Joiner Process

## Service Request

**Request ID:** SR-1001

**Requester:** Human Resources

**Priority:** Medium

**Summary:**

Create a new Microsoft Entra ID account for a new employee joining the Finance department.

---

## Employee Details

| Attribute | Value |
|-----------|-------|
| Name | Sarah Jones |
| Department | HR |
| Job Title | HR Advisor |
| Office | London |
| Company | Northwind Digital Ltd |


---

## IAM Activities

- Created Microsoft Entra ID user account
- Populated identity attributes
- Assigned the appropriate security group
- Added the user to the correct Administrative Unit
- Issued a Temporary Access Pass (TAP)
- Prepared the account for first-day access

---

## Security Controls

- Least privilege applied through security group membership
- Secure onboarding using Temporary Access Pass
- User prepared for Multi-Factor Authentication registration
- Identity managed through Microsoft Entra ID

---

## Outcome

The user was successfully onboarded and provisioned with the appropriate access for their role while following secure identity management practices.
