# PowerShell User Audit Automation

## Overview

This PowerShell script automates the retrieval of Microsoft Entra ID user information by calling the Microsoft Graph API through Azure Cloud Shell.

The script generates an identity audit report containing user account details to support governance, operational reviews and identity administration.

- PowerShell scripting
- Azure Cloud Shell
- Microsoft Graph API
- Microsoft Entra ID administration
